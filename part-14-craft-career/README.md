# Part 14 — Engineering Craft & Career

Reading code, code review, writing docs and RFCs, estimation, tech debt, mentoring, async work, and career ladders.

## Why this part exists

The 80% of senior engineering that isn't writing code. Code is a small fraction of what a senior actually produces — the rest is influence, judgment, and the documents that turn decisions into team-wide alignment. This part teaches that work.

## Chapters in this Part

1. **[Reading code at speed](01-reading-code.md)** — The skill no bootcamp teaches and every senior uses on day one of a new job.
2. **[Code review as a teaching act](02-code-review.md)** — Comments that improve the code, the author, and the team's standards over time.
3. **[Writing documentation, RFCs, and design docs](03-docs-rfcs.md)** — The artifacts that turn opinions into team alignment, with templates that work.
4. **[Estimation that doesn't lie](04-estimation.md)** — Reference classes, T-shirt sizing, when to refuse to estimate, and how to recover when reality diverges.
5. **[Tech debt as a budget](05-tech-debt.md)** — Tracking debt, paying it down, and choosing when to take more on intentionally.
6. **[Mentoring and influence](06-mentoring.md)** — Pairing, sponsorship, growing the engineers around you, and the multiplier effect that gets you promoted.
7. **[Async work, remote-first habits, career ladders](07-async-remote-career.md)** — The non-coding skills that compound across decades of remote work.
