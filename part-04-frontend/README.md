# Part 4 — Frontend Engineering

HTML, CSS, JavaScript modern features, React (hooks, RSC), Next.js, state management, Tailwind, performance (Core Web Vitals), accessibility, browser APIs, build tooling, testing, PWAs.

## Why this part exists

The frontend has the highest churn of any layer in the stack. Half of what you learn this year is replaced next year. This part teaches the parts that don't churn — the platform itself, the patterns underneath the frameworks, and the performance and accessibility work that survives every redesign.
