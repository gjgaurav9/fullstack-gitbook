# Part 4 — Frontend Engineering

HTML, CSS, JavaScript modern features, React (hooks, RSC), Next.js, state management, Tailwind, performance (Core Web Vitals), accessibility, browser APIs, build tooling, testing, PWAs.

## Why this part exists

The frontend has the highest churn of any layer in the stack. Half of what you learn this year is replaced next year. This part teaches the parts that don't churn — the platform itself, the patterns underneath the frameworks, and the performance and accessibility work that survives every redesign.

## Chapters in this Part

1. **[The modern web platform](01-web-platform.md)** — HTML semantics, CSS layout (flex, grid, container queries), JavaScript modules, and what the browser actually does between request and paint.
2. **[React deeply](02-react-deeply.md)** — Hooks, the rendering model, reconciliation, Server Components, Suspense, and the parts that trip up engineers coming from class components.
3. **[Next.js as a production framework](03-nextjs.md)** — App Router, data fetching, the caching layers, edge vs. node runtimes, and the patterns that actually scale.
4. **[State management without the rituals](04-state-management.md)** — Local state, lifted state, context, stores: when each is the right call and when reaching for Redux is a tell.
5. **[Styling at scale](05-styling.md)** — Tailwind, CSS-in-JS, design tokens, theming, and the styling decisions that survive a redesign.
6. **[Performance and Core Web Vitals](06-performance-cwv.md)** — Bundle budgets, lazy loading, image optimization, INP and LCP measured against real users.
7. **[Accessibility as a baseline](07-accessibility.md)** — ARIA, keyboard navigation, screen readers, color contrast, tested with the tools real users use.
8. **[Browser APIs, build tooling, and PWAs](08-browser-apis-pwa.md)** — Service workers, IndexedDB, Web Workers, modern bundlers, and offline-first patterns.
